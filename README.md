# e-plantShopping

## Overview
e-plantShopping is a simple web application for browsing and purchasing plants online.  
Users can view available plants, add items to cart, manage quantities, and see the total cost before checkout.

## Features
- Display available plants
- Add/remove items from cart
- Update item quantity
- Calculate total price dynamically

## Technologies Used
- HTML
- CSS
- JavaScript
